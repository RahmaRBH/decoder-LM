# GPT from Scratch

A decoder-only transformer language model built from scratch in PyTorch, trained on Python source code from the CodeSearchNet dataset. Implements the GPT-2 architecture with BPE tokenization, multi-head self-attention, and W&B experiment tracking.

## Architecture

- 6-layer decoder-only transformer
- 6 attention heads, 384-dim embeddings
- GPT-2 BPE tokenizer via `tiktoken` (50,257 vocab)
- GELU activations, pre-norm LayerNorm, dropout
- Causal (masked) self-attention

## Project Structure

```
transformer_lm.py   # model definition + training loop
prepare_data.py     # data pipeline: downloads CodeSearchNet, tokenizes, saves .bin files
checkpoints/        # saved model checkpoints (.pt)
train.bin / val.bin # tokenized dataset (generated by prepare_data.py)
```

## Setup

```bash
pip install torch tiktoken datasets wandb numpy
```

## Usage

**1. Prepare the data** (run once):
```bash
python prepare_data.py
```

**2. Train:**
```bash
python transformer_lm.py
```

Training logs to [Weights & Biases](https://wandb.ai) under the project `nanoGPT`. Checkpoints save to `checkpoints/` whenever validation loss improves.

**Resume from a checkpoint:**
```python
# In transformer_lm.py, set:
cfg.resume = True
```

## Config

All hyperparameters live in `GPTConfig` at the top of `transformer_lm.py`:

| Parameter | Default | Description |
|---|---|---|
| `n_embd` | 384 | Embedding dimension |
| `n_layer` | 6 | Transformer blocks |
| `n_head` | 6 | Attention heads |
| `block_size` | 32 | Context length (tokens) |
| `batch_size` | 64 | Batch size |
| `max_iters` | 5000 | Training iterations |
| `learning_rate` | 3e-4 | AdamW learning rate |
| `dropout` | 0.2 | Dropout rate |
